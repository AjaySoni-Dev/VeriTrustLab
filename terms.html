TERMS OF USE

VeriTrust Lab usage terms.

VeriTrust Lab provides AI-assisted scores and indicators for first-pass review. Results are probabilistic and do not establish authenticity, safety, malicious intent, or final proof.

Service Changes

The project is in active development. Available models, limits, prices, providers, persistence, and API response fields may change, and configured third-party services may be unavailable.

User Responsibility

You are responsible for having permission to submit content, protecting account and API credentials, independently reviewing results, and complying with applicable law and internal policy.

Prohibited Misuse

Do not use VeriTrust Lab for illegal surveillance, harassment, abuse, unauthorized data processing, credential theft, evasion, or harmful automation.

API Keys

Keep API keys private. Do not publish keys in frontend JavaScript, public notebooks, repositories, logs, or client-side apps.
